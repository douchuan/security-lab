# 什么是安全

> 安全是一种业务管理工具，旨在确保 IT/IS 的运行可靠且受到保护。安全的存在是为了支持组织的目标、使命和宗旨。

# 安全的目标

![](./01/cia.png)

> 概念萌芽于 1970 年代的军事研究，被 NIST 在 1990 年代确立为标准教学模型，之后通过教科书、认证体系（CISSP 等）、国际标准（ISO 27001 把 CIA. 作为信息安全目标）广泛传播

# 标准

抓手

**等保（网络安全等级保护，MLPS）**

中国的强制性合规要求，法律依据是《网络安全法》，国家标准是 GB/T 22239《网络安全等级保护基本要求》。系统按重要程度分为五级，2.0 版本（2019 年实施）把云计算、大数据、物联网、移动互联、工业控制等扩展场景纳入

![](./01/classified-protection.png)

**ISO/IEC 27000 系列**

"27000" 是整个信息安全管理标准家族的统称：

- **ISO/IEC 27001**：信息安全管理体系（ISMS）的**要求**标准，是这族里唯一可以认证的。组织建立、实施、监控、改进一套安全管理体系，通过第三方审核拿证书。2022 版有 4 大类 93 项控制措施（组织、人员、物理、技术）。
- **ISO/IEC 27002**：27001 控制措施的落地实践指南（怎么做的参考）。
- **ISO/IEC 27005**：信息安全风险管理指南。
- 家族里还有云安全（27017）、云隐私（27018）、隐私信息管理体系（27701）等。

**CC（Common Criteria，ISO/IEC 15408）**

面向产品的评估标准，不是管理体系。它用来评估一个安全产品（如防火墙、加密模块、操作系统）的安全功能和保证级别，评估结果分 EAL1~EAL7 共 7 个保证级，级别越高证明越严谨

## 国际权威参考

| 类别 | 标准/框架 |
|---|---|
| 国际权威参考 | NIST 网络安全框架（CSF 2.0）、NIST SP 800-53（安全与隐私控制）、SP 800-171（非联邦系统的受控非密信息） |
| 云服务 | SOC 2（AICPA 信任服务标准，五大准则：安全、可用、保密、处理完整、隐私）、FedRAMP（美国联邦云授权） |
| 行业强制 | PCI DSS（支付卡行业，处理卡数据必查）、HIPAA（美国医疗）、SOX（上市公司内控）、IEC 62443（工控/OT 安全） |
| 应用安全 | OWASP ASVS（应用安全验证标准）、OWASP SAMM（软件保证成熟度模型）、BSIMM（软件安全建设成熟度） |
| 隐私与数据 | GDPR（欧盟）、中国《数据安全法》《个人信息保护法》、ISO/IEC 27701（隐私信息管理体系） |
| 治理与连续性 | COBIT（IT 治理框架）、ISO 22301（业务连续性管理） |
